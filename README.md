Built a full client-side React application that acts as an AI coding mentor. Users can paste code, choose an action (Review / Explain / Improve / Generate Tests), and receive streaming responses from GPT-4o-mini. Supports multiple languages (TypeScript, Python, Java, Go, etc.). Designed with a clean split-pane UI and local API key handling for privacy.
Tech Stack:

React 18, Vite, plain CSS, OpenAI API (streaming), react-markdown, react-syntax-highlighter
Key Features:

Code Review, Explanation, Refactoring & Unit Test generation
Real-time streaming responses
Multi-language support
Dark theme, responsive UI
API key stored only in browser (localStorage)


Sole developer – designed the UI, implemented streaming logic, system prompts for different modes, and overall architecture.
